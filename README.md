# Operating Cloud Databases

**PostgreSQL, MongoDB, and Reliable Data Systems**

An open textbook and a complete 15-week database administration course by
Atilio Barreda.

- **[Download the textbook (PDF)](https://raw.githubusercontent.com/lolusername/CST4714_OER/main/Operating_Cloud_Databases.pdf)**: the complete 161-page book.
- **[Open the course materials](course_materials/README.md)**: each week's readings, PowerPoint, individual labs, and notebooks, plus the syllabus and projects.
- **[Instructor guides](course_materials/instructor/README.md)**: lesson plans, demonstrations, troubleshooting, and adaptation.

The textbook is PDF-only. All companion teaching materials remain editable.
To download everything together, choose **Code > Download ZIP** above.
