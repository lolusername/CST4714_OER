page says to submit one. Open the matching week page for context and directions.

Click **Open in Colab** to open a notebook directly, or **View on GitHub** to
preview its source. Each link targets that week's public notebook on `main`.
Save a working copy in Drive and
run the cells in order. Local Jupyter is also supported.
